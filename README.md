# 源界 · Origin World

第一期社交与故事演示。玩家可以进入第一人称空间，也可以打开世界线阅读动态与故事。拍照、合影和文字发布能引起不同居民的回应，实际发生的接触会沉淀为章节。三期建设方向见 [演示分期](DEMO_PLAN.md)。

## 第一次试玩

在海边会客厅按 P 取景，拍一张照片，写一句话发到动态里。打开「世界线」看谁注意到了它。居民对照片感兴趣时可能走近你，在近处可以邀请对方合影。再打开世界线，对照刚刚经历的事读一遍新记录。

## 创作分工

创作者提出并持续调整社交玩法。早期试玩中，按任务指引与居民交互的感觉太强，于是把拍照、发动态和居民主动靠近串成一次自由行动，让实际发生的相遇成为故事的素材。Codex 协助编写原型和自动化测试。第三方角色模型与图形库的署名见文末。

## 本地运行

需要 Node.js 20 或更高版本，无需安装运行时依赖。

```sh
node start.mjs
```

打开 http://127.0.0.1:4173 。可用 PORT 环境变量选择其他端口。dist 可以直接部署到静态托管。

## 现在可以体验

- 按 P 进入随身摄影模式，可切换自拍，拍下真实画面后配文发动态。
- 打开「世界线」，阅读不同居民的延迟回应和有事件来源的章节。
- 角色对动态产生兴趣后，可以走到发布者身边继续交流。近场可邀请合影或贴贴，接受后才执行。
- 暂停或恢复前台托管演示，发布与评论更新时会保留正在输入的草稿。

- 进入海边会客厅，用第一人称走动、转头和推门。
- 拿起桌上的照片，递给闻汐。它会走到画框前挂上照片。
- 使用相机实际拍摄眼前场景，在手记中保存照片，并在会客厅展出。
- 通过海边的门进入潮汐档案馆或雾林邮局，取一件有来源的物品，再返回群岛。
- 查看事件、物品和拍摄记录。接管拾一或自己创建的居民，交还后让角色继续移动。
- 刷新后继续上次的位置、参与身份、展出作品和持有物品。

## 操作

W A S D 或方向键移动，鼠标转头，E 与视线中央的物件或角色互动。P 切换摄影模式，F 拍照或查看持有物。摄影模式自动放开鼠标，拖动取景，再点击自拍与快门按钮。G 把手中物品收进随身库存，Tab 打开手记，Esc 放开鼠标。浏览器无法锁定鼠标时，按住画面拖动也能转头。

触摸屏使用左侧摇杆移动，滑动右侧画面转头，点 E 操作。环境声由玩家手动开启。

## 当前范围

这一版是单人本地空间。居民按本地兴趣策略、实际位置和事件记忆行动，尚未接入大模型、离线后台或跨设备多人服务器。所谓前台托管演示只在页面可见时推进，不伪造离线运行记录。照片发布后通常在10至24秒内被合资格的居民看见，也允许不感兴趣而保持沉默。角色的视线交互由射线命中和距离校验控制，事件见证按所在世界与距离记录。世界与作品保存在当前浏览器的 localStorage。

早期的文字图鉴保留在 atlas.html，用来查看前期的世界与角色创作流程。图鉴与实时空间目前各用独立存档，图鉴里的自建世界尚未生成可进入的3D场景。

## 可继续修改的模块

| 文件 | 职责 |
| --- | --- |
| dist/js/spatial/worldline.js、dist/worldline.css | 世界线、动态、章节与发布界面 |
| dist/js/spatial/social.js | 动态可见边界、延迟决策、实际接近与亲密邀请、章节事实来源 |
| dist/js/spatial/main.js | 第一人称控制、现场交互、居民调度与手记界面 |
| dist/js/spatial/environment.js | 三个实时场景、可操作物件、碰撞与光照 |
| dist/js/spatial/actors.js | 角色外观、行走、持物、转头和第一人称手持物 |
| dist/js/spatial/state.js | 控制权、物品归属、事件、角色记忆与持久化 |
| dist/js/spatial/navigation.js | 绕开桌墙和关闭的门，寻找可行走路线 |
| dist/js/engine.js | 早期图鉴的文本世界与旅程模型 |

界面与实际行为可以分别迭代。状态动作入口用于校验事件，之后接入模型时可让模型选择已有动作，并由世界确认动作能否执行。

## 依赖与美术

视觉改为月白、雾蓝与香槟金的海岸花园。首屏使用生成的世界印象图，进入后仍是可走动、可拍摄的实时 3D 温室与花园。石材、紫藤和主视觉位于 dist/assets。人物使用三款可动的 VRoid CC0 示例素材，作为这轮视觉演示的临时人物；它们不是源界原创角色。来源和授权见 [人物素材说明](dist/assets/models/NOTICE.md)。人物模型经过纹理优化，单款约 6 MB，首开会等待当前居民载入。

早期图鉴的四张场景插画来自本项目的创作过程。当前入口插画、石材纹理与紫藤素材由 AI 为本项目生成。项目自有内容保留权利，第三方素材和程序库分别适用其原有许可。
